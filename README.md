# artworkship.com — first version

This is a static website prepared for GitHub Pages.

## Files

- `index.html` — homepage and gallery
- `styles.css` — responsive minimalist layout
- `script.js` — fullscreen artwork viewer
- `assets/artworks/` — works 250001–250029
- `assets/brand/` — rk logo
- `CNAME` — custom domain configuration

## Publish on GitHub Pages

1. Create a new public repository.
2. Upload every file and folder from this package to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. In the domain registrar DNS settings, connect `artworkship.com` according to GitHub Pages' custom-domain instructions.
7. In GitHub Pages settings, confirm the custom domain and enable HTTPS when available.

The gallery currently contains no titles or descriptions. Each image is displayed as supplied, including the artwork number already visible inside the image.
